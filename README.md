# Formula 1 Performance Analytics Dashboard

## Project Overview

This project analyzes Formula 1 race data across multiple seasons to uncover insights into driver performance, constructor dominance, race competitiveness, and qualifying impact.

Using Python-based data analysis and visualization techniques, the project explores over 25,000 race records through exploratory data analysis (EDA), statistical summaries, and interactive visualizations.

---

## Objectives

- Analyze driver and constructor performance trends
- Identify dominant teams across seasons
- Study the impact of starting grid positions on race outcomes
- Explore fastest lap performance and race competitiveness
- Build meaningful visualizations and dashboards

---

## Dataset Information

- Dataset: Formula 1 Race Results Dataset
- Rows: 25,000+
- Columns: 15
- Features include:
  - Season
  - Driver Name
  - Constructor
  - Grid Position
  - Final Position
  - Points
  - Fastest Lap
  - Race Status

## Key Insights

- Front grid positions strongly influence race outcomes.
- Certain constructors dominate multiple Formula 1 eras.
- Consistent podium finishes contribute significantly to long-term championship success.
- Fastest lap rankings often correlate with stronger race finishes.

---

## Limitations

- Some race completion times contain inconsistent formatting.
- Historical scoring systems changed across seasons.
- Dataset does not include weather or pit stop strategy information.
